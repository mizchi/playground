# 2026-11-10-fable-compositions

## 目的

LLM に「作曲」をさせる実験。録音やサンプルは使わず、音名の文字列で書いた楽譜を
Web Audio API の自作シンセで鳴らす。ジャンルを変えて 6 曲と、反応の良かった 4・5 の路線で書いた長編 1 曲。

| # | 曲名 | ジャンル | 仕掛け |
|---|------|----------|--------|
| 1 | 雨宿り | Lo-fi Hip Hop | Dm9–G13–Cmaj9–A7♭13、16 分スウィング、高域カット |
| 2 | ピクセルの朝焼け | Chiptune | 矩形波 2 声 + 三角波 + ノイズのみ |
| 3 | 二声のインヴェンション | Baroque | 主題の模倣と役割交換、ピカルディ終止 |
| 4 | 潮汐 | Minimal / Ambient | 7/8 拍子。7・6・11 音の音型の位相ずれ |
| 5 | 深夜の首都高 | Synthwave | 16 分のノコギリ波ベース、3+3+2 のリード |
| 6 | 宵の庭 | 和風 | 都節音階のみ。箏 + 尺八風の笛 |
| 7 | 環状線 | Minimal Synthwave（長編 3:00） | 4 と 5 の掛け合わせ。7 音と 6 音の型を 84 小節リセットせずに回し、4 つ打ちに乗せる。ニ長調 → ホ長調 |

## 動かし方

`index.html` をブラウザで開いて曲を選ぶ（依存なし、ビルドなし。フォントだけ Google Fonts）。

楽譜は `index.html` 内の `SONGS`。記法は `c4`（音名）、`_3`（長さ）、`.`（休符）、
`c4+e4+g4`（和音）、`^`（アクセント）、`|`（小節線）。小節の長さは読み込み時に検算され、ずれると console にエラーが出る。

```bash
node verify.cjs            # 全曲をオフラインレンダリングして検算・音量チェック (playwright が必要)
node verify.cjs shot.png   # ついでにスクリーンショットを保存
```

7 曲目のためにシンセ側へ足したもの: トラックごとのフィルター／音量の自動操作 (`auto`)、
パン、付点 8 分のピンポン・ディレイ、キックによるサイドチェイン (`duck`)、クラッシュとライザー、
ピアノロールのクリックによる頭出し。

## 結果

- 7 曲とも検算エラーなし、ピーク 0.58〜0.77 に収まる（`verify.cjs` の出力。全曲で 2 分強かかる）。
- 実再生とピアノロールからの頭出しは、ヘッドレスブラウザでエラーなく動くことを確認。
- 確認できたのは「楽譜が拍に収まっている」「音が出て歪まない」まで。
  実際に聴いて良い曲かどうかは機械的には検証していない。
