# leanmath — 「GRH が真だったら」で何が掘れるか

[図解：三つの振動を抑えるには、時計の目盛りをどこに置けばいいか？](reports/harmonic-clock/README.md)

## 目的

リーマン予想（RH）が解決されたという前提に立ち、そこから確定する事実のうち **人間が掘る価値が低いとして放置してきた隅**を、計算と Lean で探索する。

### 前提についての注意（先に読むこと）

- 提示された `https://alpo.ge/remark.pdf` はこの環境から取得できなかった（DNS 解決に失敗）。そのため中身は検証していない。
- だからこの実験では、論文の正否に依存しない形をとる。**解析的な仮定は Lean の明示的な仮定 `(h : RH)` / `(h : GRH)` / `(h : BachBound)` として置き**、そこから先を初等的に導く。`axiom` は使わない。
- **RH と GRH は別物**。依頼文にある帰結のほとんどは、ζ の RH ではなく **Dirichlet L 関数（または Dedekind ζ・Hecke L）の GRH** を必要とする。ζ の RH だけで確定するのは下表の「RH」行のみ。

|---|---|---|

| Miller 判定の決定化・因数分解 ≡ φ(n) | GRH（Dirichlet） | Miller 1976, Bach 1990 |

| HN ∈ AM、代数的 P vs NP との接続 | GRH（Dedekind） | Koiran 1996, Bürgisser |
| PARI/Magma の類群計算・CM 法の曲線生成 | GRH（Dedekind/Hecke） | Buchmann, Bach |

## 着眼点：すべてを 1 つの量 G(n) に集約する

「乱択が要らなくなる」系の帰結の大半は、次の 3 段の議論でできている。

1. （初等的・無条件）悪い入力は (ℤ/nℤ)ˣ の **真部分群** H に入る
   - 例: Miller 判定の strong liar、平方根なら平方剰余、ℓ 乗根なら ℓ 乗剰余
2. （初等的・無条件）真部分群は **G(n) 以下**のどこかの単数を取りこぼす
3. （解析的・GRH）**G(n) ≤ 2 ln² n**（Bach 1990）

ここで G(n) は次のように定める（Lean では `genBound`）。

> **G(n) := 「1, …, x のうち n と互いに素なものが (ℤ/nℤ)ˣ を生成する」ような最小の x**

GRH が入るのは 3 の一点だけで、1 と 2 は形式化できる初等数学である。そこで次の 2 つを行った。

- **計算**: G(n) の実際の値と GRH 上界 2 ln² n のあいだの「余白」を測る
- **Lean**: 1 と 2 を形式化する。3 は `BachBound` という仮定として置く

## 動かし方


## 結果

### 発見 1: 「平方根が最難ではない素数」の密度 δ ≈ 0.14647 と、それを説明するモデル

素数 p では (ℤ/pℤ)ˣ が巡回群なので、G(p) = max_{ℓ | p−1} n_ℓ(p) となる（n_ℓ(p) は最小の ℓ 乗非剰余）。決定的に平方根を求めるには n₂(p) まで探索すればよく、3 乗根なら n₃(p) まで探索すればよい。

**G(p) > n₂(p)**、つまり平方根より ℓ ≥ 3 乗根の探索のほうが長くなる素数の割合は、10² から 2³² までのすべての桁で 14.6% 付近に張り付いた。

| 範囲 | 素数の数 | G(p) > n₂(p) の割合 |
|---|---|---|
| 10⁶–10⁷ | 586,081 | 0.146579 |
| 10⁷–10⁸ | 5,096,876 | 0.146503 |
| 10⁸–10⁹ | 45,086,079 | 0.146462 |
| 10⁹–2³² | 152,432,687 | **0.146470** (σ ≈ 2.9×10⁻⁵) |

この値を予測する Chebotarev 型のモデルを作った（`explore/model_delta.py`）。

- 小さい素数 q₁ = 2, q₂ = 3, … のべき剰余性は独立と仮定する。すると P(n₂ = qᵢ) = 2⁻ⁱ、P(ℓ | p−1) = 1/(ℓ−1)、P(q₁…qᵢ がすべて ℓ 乗剰余) = ℓ⁻ⁱ となる。
- 素朴な独立モデル: δ = Σᵢ 2⁻ⁱ (1 − ∏_{ℓ≥3} (1 − 1/((ℓ−1)ℓⁱ))) = **0.146677**。観測とのずれは 7σ で、合わない。
- **相互法則による絡み合いの補正**: ℓ ≡ 1 (mod 4) かつ ℓ | p−1 なら、(ℓ/p) = +1 が自動的に決まる。この効果を入れると **0.146459** になり、観測とのずれは **0.4σ**。

つまり「乱択を GRH で除去したときに、どの根の計算がボトルネックになるか」は、相互法則まで含めたべき剰余の統計だけで定量的に説明できた。調べた範囲では文献で見た覚えがない、地味だが新しい定数である（未確認）。

**大きな素数でも同じ値になる。** 10¹² と 10¹⁵ の近くでそれぞれ約 10⁸ 個の連続する素数を調べた（`results/bottleneck.md`）。

| 範囲 | 素数の数 | δ（観測） | 補正モデルとの差 |
|---|---|---|---|
| [2³⁰, 2³²) | 148,880,193 | 0.146470 | +0.4σ |
| 10¹² 付近 | 101,331,814 | 0.146398 | −1.7σ |
| 10¹⁵ 付近 | 101,333,575 | 0.146468 | +0.3σ |

**ボトルネックの内訳までモデルで予測できる。** 同じモデルで「どの ℓ がボトルネックになるか」（G(p) = n_ℓ(p) となる最小の ℓ）の分布を計算した（`explore/model_bottleneck.py`）。p ∈ [2³⁰, 2³²) での比較は次の通り。

| ℓ | 補正モデル | 観測 | 差 | 素朴モデルとの差 |
|---|---|---|---|---|
| 3 | 0.099073 | 0.099076 | +0.1σ | +0.2σ |
| 5 | 0.023772 | 0.023766 | −0.5σ | **−17.9σ** |
| 7 | 0.010529 | 0.010533 | +0.5σ | +0.5σ |
| 11 | 0.003780 | 0.003784 | +0.8σ | +0.8σ |
| 13 | 0.002615 | 0.002610 | −1.0σ | −1.0σ |

- 3 つの範囲 × 8 個の ℓ、計 24 の比較のうち、2σ を超えたのは 2 つだけ（統計的に想定される数）。
- 素朴モデルで δ が 7σ ずれた原因は、ほぼ **ℓ = 5 の一項だけ**だった。5 ≡ 1 (mod 4) なので、p ≡ 1 (mod 5) なら 5 は自動的に平方剰余になり、n₂(p) = 5 となることはない。独立モデルはこの起こりえない組み合わせ（n₂ = 5 かつ 5 乗根がボトルネック）にも確率を割り当てるので、ℓ = 5 の割合を過大評価する（0.02399 vs 観測 0.02377）。
- 13 や 17 も ≡ 1 (mod 4) だが、n₂(p) > 13 となる素数自体が稀なので、効果は誤差に埋もれる。

予想: この密度は存在し、補正モデルの値 0.146459… に等しい。GRH の下では Chebotarev 密度定理の有効版から証明できる可能性がある。

### 発見 2: G(p) の記録保持者はすべて平方非剰余が支配している

p < 2³² で G(p) の記録を更新した 20 個の素数は、すべて n₂(p) の記録保持者と一致した。つまり、ある範囲で決定的な根の計算が最も難しい素数は、常に「平方根が難しい素数」だった。

- 最大値は G(2929911599) = 97、G/ln² p = 0.204
- Bach の上界の係数 2 に対して、実測の上限は p ≥ 10⁶ で約 0.24。**約 8〜10 倍の余白**がある
- 3 乗非剰余の記録: n₃(2741702809) = 59（n₃/ln² p ≈ 0.12）

### 発見 3: 合成数 n は素数の約 2 倍きつく、ω(n) とともに G(n) が増える

全 n ≤ 4×10⁵ について計算した（`results/composite.md`）。

- **Bach の上界 G(n) ≤ 2 ln² n の破れはゼロ**。n > 100 では G(n) ≤ ln² n すら成り立っていた。この範囲では、Miller 判定の決定版は GRH なしで（有限検証として）正しい。
- 10⁵ 台で、max G/ln² は合成数 0.49、素数 0.26。
- 異なる素因数の数 ω(n) ごとの G(n) の平均は 3.9 → 6.8 → 11.2 → 17.1 → 24.9 → 35.6（ω = 1…6）と、ほぼ線形以上に増える。2-rank が ω(n) に比例して増え、それだけ多くの指数 2 部分群から脱出しなければならないためと解釈できる。
- 奇数 n の記録保持者は 3·5·7·…（小さい奇素数の積）に、大きな素因数が 1 つ付いた形が多い。例: 268719 = 3·11·17·479 で G = 67。

### 発見 4: Miller の証明は大きく損をしている

実際の最小 Miller witness W(n) は、n ≤ 4×10⁵ の奇合成数で最大でも **3**（n = 2047 が初の 2-強擬素数）。一方、証明が使う G(n) は最大 67 に達する。

GRH を経由する証明は「liar の集合 ⊂ 真部分群」という粗い包含しか使わない。そのため、実際の必要量の 20 倍以上を保証していることになる。liar 集合の大きさ（φ(n)/4 以下）を使った、より鋭い条件付き上界はほぼ未開拓である。

### 副産物: RH・GRH 上界との比較

- **素数ギャップ**: p < 2³² の最大ギャップ比 gap/(√p ln p) は p = 7 での 0.777。RH 上界の 0.88 は満たしており、p > 10⁶ では 0.005 未満（`results/gaps.md`）。
- **等差数列中の最小素数**: q ≤ 2×10⁴ で P(q) > q² となる q はなく、GRH 上界 (φ(q) ln q)² の破れもない。P(q)/(φ(q) ln² q) の最大値は q が大きくなると 2 前後に下がっていく（2.9 → 2.2 → 2.1 → 1.8）（`results/ap.md`）。

## Lean（`lean/`）

Lean 4.36.0 + Mathlib v4.36.0 で **`sorry` なしでビルドが通る**。主定理は次の 2 つ。依頼文のリストのうち「素数判定」と「素数を法とする平方根」の 2 項目にあたる。

```lean
theorem millerDet_iff (hB : BachBound) (n : ℕ) : millerDet n = true ↔ n.Prime
theorem detSqrt_sq (hB : BachBound) {p : ℕ} [Fact p.Prime] (hp2 : p ≠ 2) {a : ZMod p}
    (ha : IsSquare a) : detSqrt p a ^ 2 = a
```

`millerDet` と `detSqrt` は `#eval` で実行できる（`millerDet` は基数 2 … 2(⌊log₂ n⌋+1)² の決定的 Miller 判定）。GRH 由来の入力は仮定 `hB : BachBound` の一点だけで、それ以外はすべて初等的に証明した。`#print axioms` が返すのは `propext`, `Classical.choice`, `Quot.sound` のみである。

| ファイル | 定理 | 内容 |
|---|---|---|
| `Hypotheses.lean` | — | `RH`（Mathlib の `RiemannHypothesis`）、`GRH`（Dirichlet L）、`genBound` = G(n)、`BachBound`（定義のみ） |
| `GenBound.lean` | `exists_not_mem_le_genBound` | 真部分群は G(n) 以下の単数を取りこぼす |
| | `exists_nonsquare_le_genBound` | 最小平方非剰余 ≤ G(p)（無条件） |
| | `powers_ne_top` / `exists_nonpower_le_genBound` | ℓ \| p−1 なら ℓ 乗剰余群は真部分群（Cauchy）。よって n_ℓ(p) ≤ G(p) |
| | `exists_small_nonsquare` / `exists_small_nonpower` | `BachBound →` 平方・ℓ 乗非剰余が 2 ln² p 以下に存在する |
| `Miller.lean` | `strongLiars_le_proper` | **Monier–Rabin**: 奇合成数の strong liar は真部分群に入る（無条件） |
| | `exists_witness_le_genBound` | 最小 Miller witness ≤ G(n)（無条件） |
| | `exists_small_witness` | `BachBound →` witness ≤ 2 ln² n |
| | `powMod_eq`, `sprp_iff`, `liar_of_prime` | 実装（高速べき乗・強擬素数判定）と仕様の一致、素数ではすべての単数が liar |
| | `millerDet_iff` | `BachBound →` `millerDet` は素数判定として正しい |
| `Sqrt.lean` | `tsLoop_sq` / `tonelliShanks_sq` | Tonelli–Shanks は平方非剰余 z が与えられれば正しい（無条件、ループ不変条件による証明） |
| | `detSqrt_sq` | `BachBound →` `detSqrt`（z ≤ 2(⌊log₂ p⌋+1)² を Euler 規準で探索し、Tonelli–Shanks を実行）は、平方剰余すべてに平方根を返す |

Monier–Rabin の証明は教科書の「Carmichael 数かどうか」による場合分けを使わず、n が素数べきかどうかだけで分けた。

- **n = p^e（e ≥ 2）の場合**: Fermat liar の部分群 {a | a^(n−1) = 1} を使う。1+p がこの部分群に入らないことは、mod p² で (1+p)^N = 1 + Np となることから示せる。
- **n = n₁n₂（互いに素）の場合**: u^(2^k·d) = −1 となる単数 u が存在する最大の k をとり、H = {a | a^(2^k·d) = ±1} とする。中国剰余定理で (−1, 1) を持ち上げると H の外の元になる。この議論は n が Carmichael 数でなくてもそのまま通る。

## 次に掘る候補

- δ の存在と値を GRH の下で証明する（有効 Chebotarev + n₂ の裾の評価）。補正モデルの式はそのまま候補になる。
- 補正モデルの残りの絡み合い（ℓ ≡ 3 (mod 4) では (ℓ/p) = (−1/p) となり、複数の ℓ の平方剰余性が連動する）を入れて、10⁻⁶ 精度で検証する。
- 合成数 n に対する G(n) の漸近形を ω(n) の関数として求め、Bach 定数を ω に依存した形に精密化する。
- liar 集合の濃度を使って、W(n) の GRH 条件付き上界を 2 ln² n よりも鋭くする。
- Lean: ℓ 乗根（Adleman–Manders–Miller）も同様に形式化する（ℓ 乗非剰余の探索部分は `exists_small_nonpower` で済んでいる）。
- Lean: 解析的な橋 `GRH → BachBound` は今の Mathlib では遠い。代わりに、有限範囲 n ≤ N で `BachBound` が成り立つことを計算で証明し、その範囲では無条件に `millerDet` が正しいことを示す。
