# leanmath — 「GRH が真だったら」で何が掘れるか

## 目的

リーマン予想（RH）が解決されたという前提に立ち、そこから確定する事実のうち **人間が掘る価値が低いとして放置してきた隅**を、計算と Lean で探索する。

### 前提についての注意（先に読むこと）

- 提示された `https://alpo.ge/remark.pdf` はこの環境から取得できなかった（DNS 解決に失敗）。そのため中身は検証していない。
- だからこの実験では、論文の正否に依存しない形をとる。**解析的な仮定は Lean の明示的な仮定 `(h : RH)` / `(h : GRH)` / `(h : BachBound)` として置き**、そこから先を初等的に導く。`axiom` は使わない。
- **RH と GRH は別物**。依頼文にある帰結のほとんどは、ζ の RH ではなく **Dirichlet L 関数（または Dedekind ζ・Hecke L）の GRH** を必要とする。ζ の RH だけで確定するのは下表の「RH」行のみ。

## 着眼点：すべてを 1 つの量 G(n) に集約する

「乱択が要らなくなる」系の帰結の大半は、次の 3 段の議論でできている。

1. （初等的・無条件）悪い入力は (ℤ/nℤ)ˣ の **真部分群** H に入る
   - 例: Miller 判定の strong liar、平方根なら平方剰余、ℓ 乗根なら ℓ 乗剰余
2. （初等的・無条件）真部分群は **G(n) 以下**のどこかの単数を取りこぼす
3. （解析的・GRH）**G(n) ≤ 2 ln² n**（Bach 1990）

ここで G(n) は次のように定める（Lean では `genBound`）。

> **G(n) := 「1, …, x のうち n と互いに素なものが (ℤ/nℤ)ˣ を生成する」ような最小の x**

GRH が入るのは 3 の一点だけで、1 と 2 は形式化できる初等数学である。そこで次の 2 つを行った。

- **計算**: G(n) の実際の値と GRH 上界 2 ln² n のあいだの「余白」を測る
- **Lean**: 1 と 2 を形式化する。3 は `BachBound` という仮定として置く

## 結果

### 発見 1: 「平方根が最難ではない素数」の密度 δ ≈ 0.14647 と、それを説明するモデル

素数 p では (ℤ/pℤ)ˣ が巡回群なので、G(p) = max_{ℓ | p−1} n_ℓ(p) となる（n_ℓ(p) は最小の ℓ 乗非剰余）。決定的に平方根を求めるには n₂(p) まで探索すればよく、3 乗根なら n₃(p) まで探索すればよい。

**G(p) > n₂(p)**、つまり平方根より ℓ ≥ 3 乗根の探索のほうが長くなる素数の割合は、10² から 2³² までのすべての桁で 14.6% 付近に張り付いた。

| 範囲 | 素数の数 | G(p) > n₂(p) の割合 |
|---|---|---|
| 10⁶–10⁷ | 586,081 | 0.146579 |
| 10⁷–10⁸ | 5,096,876 | 0.146503 |
| 10⁸–10⁹ | 45,086,079 | 0.146462 |
| 10⁹–2³² | 152,432,687 | **0.146470** (σ ≈ 2.9×10⁻⁵) |

この値を予測する Chebotarev 型のモデルを作った（`explore/model_delta.py`）。

- 小さい素数 q₁ = 2, q₂ = 3, … のべき剰余性は独立と仮定する。すると P(n₂ = qᵢ) = 2⁻ⁱ、P(ℓ | p−1) = 1/(ℓ−1)、P(q₁…qᵢ がすべて ℓ 乗剰余) = ℓ⁻ⁱ となる。
- 素朴な独立モデル: δ = Σᵢ 2⁻ⁱ (1 − ∏_{ℓ≥3} (1 − 1/((ℓ−1)ℓⁱ))) = **0.146677**。観測とのずれは 7σ で、合わない。
- **相互法則による絡み合いの補正**: ℓ ≡ 1 (mod 4) かつ ℓ | p−1 なら、(ℓ/p) = +1 が自動的に決まる。この効果を入れると **0.146459** になり、観測とのずれは **0.4σ**。

つまり「乱択を GRH で除去したときに、どの根の計算がボトルネックになるか」は、相互法則まで含めたべき剰余の統計だけで定量的に説明できた。調べた範囲では文献で見た覚えがない、地味だが新しい定数である（未確認）。

予想: この密度は存在し、補正モデルの値 0.14646 に等しい。GRH の下では Chebotarev 密度定理の有効版から証明できる可能性がある。

ボトルネックになった ℓ の内訳（p < 2³²）は、ℓ = 2 が 85.35%、3 が 9.91%、5 が 2.38%、7 が 1.05%、… である（`results/primes.md`）。

### 発見 2: G(p) の記録保持者はすべて平方非剰余が支配している

p < 2³² で G(p) の記録を更新した 20 個の素数は、すべて n₂(p) の記録保持者と一致した。つまり、ある範囲で決定的な根の計算が最も難しい素数は、常に「平方根が難しい素数」だった。

- 最大値は G(2929911599) = 97、G/ln² p = 0.204
- Bach の上界の係数 2 に対して、実測の上限は p ≥ 10⁶ で約 0.24。**約 8〜10 倍の余白**がある
- 3 乗非剰余の記録: n₃(2741702809) = 59（n₃/ln² p ≈ 0.12）

### 発見 3: 合成数 n は素数の約 2 倍きつく、ω(n) とともに G(n) が増える

全 n ≤ 4×10⁵ について計算した（`results/composite.md`）。

- **Bach の上界 G(n) ≤ 2 ln² n の破れはゼロ**。n > 100 では G(n) ≤ ln² n すら成り立っていた。この範囲では、Miller 判定の決定版は GRH なしで（有限検証として）正しい。
- 10⁵ 台で、max G/ln² は合成数 0.49、素数 0.26。
- 異なる素因数の数 ω(n) ごとの G(n) の平均は 3.9 → 6.8 → 11.2 → 17.1 → 24.9 → 35.6（ω = 1…6）と、ほぼ線形以上に増える。2-rank が ω(n) に比例して増え、それだけ多くの指数 2 部分群から脱出しなければならないためと解釈できる。
- 奇数 n の記録保持者は 3·5·7·…（小さい奇素数の積）に、大きな素因数が 1 つ付いた形が多い。例: 268719 = 3·11·17·479 で G = 67。

### 発見 4: Miller の証明は大きく損をしている

実際の最小 Miller witness W(n) は、n ≤ 4×10⁵ の奇合成数で最大でも **3**（n = 2047 が初の 2-強擬素数）。一方、証明が使う G(n) は最大 67 に達する。

GRH を経由する証明は「liar の集合 ⊂ 真部分群」という粗い包含しか使わない。そのため、実際の必要量の 20 倍以上を保証していることになる。liar 集合の大きさ（φ(n)/4 以下）を使った、より鋭い条件付き上界はほぼ未開拓である。

### 副産物: RH・GRH 上界との比較

- **素数ギャップ**: p < 2³² の最大ギャップ比 gap/(√p ln p) は p = 7 での 0.777。RH 上界の 0.88 は満たしており、p > 10⁶ では 0.005 未満（`results/gaps.md`）。
- **等差数列中の最小素数**: q ≤ 2×10⁴ で P(q) > q² となる q はなく、GRH 上界 (φ(q) ln q)² の破れもない。P(q)/(φ(q) ln² q) の最大値は q が大きくなると 2 前後に下がっていく（2.9 → 2.2 → 2.1 → 1.8）（`results/ap.md`）。

## 次に掘る候補

- δ の存在と値を GRH の下で証明する（有効 Chebotarev + n₂ の裾の評価）。ℓ = 3 が最難になる割合 9.91% も同じモデルで予測できるはず。
- 合成数 n に対する G(n) の漸近形を ω(n) の関数として求め、Bach 定数を ω に依存した形に精密化する。
- liar 集合の濃度を使って、W(n) の GRH 条件付き上界を 2 ln² n よりも鋭くする。
- Lean: `strongLiars_le_proper` と `powers_ne_top` を埋め、`millerDet n = true ↔ n.Prime`（`BachBound` 仮定）を完成させる。
