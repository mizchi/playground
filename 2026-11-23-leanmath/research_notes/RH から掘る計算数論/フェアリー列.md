# フェアリー列で素数倍の周波数の求積誤差が一致する帯域

## どこまで古典的な結果か

### Takeaway

分母上限を固定した既約分数で関数の平均を取るとき、固定周波数での RH 誤差は既知。ここでは分母上限と同時に発散する周波数で、何個の高調波にその評価が戻るかを調べる。[Kanemitsu–Yoshimoto](https://bibliotekanauki.pl/articles/1391153.pdf) [Weber](https://arxiv.org/abs/1906.07628)

### Cited Findings

- 正規化に使う分数は円周上で 0 と 1 を同一視し、`F_N={a/q : 1≤a≤q≤N, gcd(a,q)=1}`、`Φ(N)=|F_N|∼3N²/π²` とする。通常の RH はすべての ε>0 に対する `M(x)=O_ε(x^(1/2+ε))` と同値である。M はメルテンス関数。[Kanemitsu–Yoshimoto, pp. 351–352](https://bibliotekanauki.pl/articles/1391153.pdf)
- 一般の Farey 和とフーリエ係数の台が持つ約数の効果はすでに研究されている。[Weber, §§2–3](https://arxiv.org/abs/1906.07628)
- Hurst は 10^16 までの M の零点を全数計算し、桁ごとの個数を報告している。次節の計算と重なる 10^6, 10^7, 10^8 の個数は 5361, 12546, 41908。[Hurst, §6.1](https://arxiv.org/abs/1610.08551)

### Inferences

周波数 k での複素指数関数の標本和を A_N(k)=Σ_{x∈F_N} exp(2πikx) と書く。k>0 では積分が 0 なので A_N(k)/Φ(N) が求積誤差。分母 q を固定して gcd=1 の指示関数にメビウス反転を使い、等比級数を足すと Σ_{d|gcd(k,q)} d μ(q/d) を得る。順序交換で A_N(k)=Σ_{d|k} d M(⌊N/d⌋)。この既知の構造から下の判定が出る。

### Gaps

調べた Farey 和・求積・円分多項式の積の文献では、次節の同時一致が起きる帯域の完全分類とその素数割合を報告した論文を特定できなかった。優先権の確定には両分野の追加調査が要る。

## どの周波数で RH の誤差に戻るか

### Takeaway

素数 p>3 と分母上限 1270p≤N<1271p に対して、周波数 p, 2p, 3p の標本和は 1, 2, 3 の標本和にそれぞれ等しい。4p では和に −16p の補正が入る。最初の三つの正規化誤差は RH で O_ε(N^(−3/2+ε))、第4の正規化誤差は Θ(N^(−1))。いずれの定数も p に一様である。

### Cited Findings

- 以下の推論に入る既知の解析的な入力は Φ の漸近式と通常の RH による M の評価である。[Kanemitsu–Yoshimoto, pp. 351–352](https://bibliotekanauki.pl/articles/1391153.pdf)

### Inferences

1. p が素数、p∤r、m=⌊N/p⌋ とする。pr の約数を d|r と pd (d|r) に分けると A_N(pr)−A_N(r)=p A_m(r) を得る。p>h のとき r=1,…,h で同時に一致する必要十分条件は、d=1,…,h のすべてで M(⌊m/d⌋)=0 が成立すること。A_m(r) の約数和で次数を 1 から順に上げると未決の項が r M(⌊m/r⌋) だけ残る。この m の集合を Z_h とする。m≥1 を対象とする。
2. m=1270 では M(1270), M(635), M(423), M(317) が順に 0,0,0,−4。したがって A_1270 は第4高調波で −16 となる。p>3 は 4 とも互いに素。m=1269 と 1271 では M(m)=1 で、第1高調波だけでも +p の補正となる。
3. 固定された r に対し RH と約数和から A_N(r)=O_{r,ε}(N^(1/2+ε))。m が固定なら p と N は同程度なので、非零の p A_m(r) はこの誤差より大きい。境界を一つまたぐと 1/N の誤差項が復活する。RH は有限の一致や分類に必要なく、その帯域で小さくなる誤差の指数を与える。

### Gaps

O の定数はここで数値化していない。指定した N の区間に p が必ずあるという実用的な有限閾値もまだ出していない。厳密な例は先に p を取り N=1270p と置くだけで構成できる。

## 同時に三つ以上が消える頻度はどのくらいか

### Takeaway

分母上限 N に対して p≤N の素数を一様に数え、r=1,…,h の標本和が低周波にすべて厳密一致する割合の極限を δ_h とする。この極限は無条件で存在する。h=3 では 0.000000667132540 と 0.000000667142765 の間、h=4 では 0 以上 0.00000000001023 未満となった。h=4 の存在は開いた探索課題である。

### Cited Findings

- 10^8 を超える端の評価には、Hurst の §6.1 の桁別零点個数を使った。生の全零点座標は本実験では取得していない。[Hurst](https://arxiv.org/abs/1610.08551)

### Inferences

固定 m の帯域 N/(m+1)<p≤N/m の素数割合は素数定理で 1/m−1/(m+1) に近づく。m>B の部分は π(N/(B+1))/π(N) 以下で、上極限は 1/(B+1) 以下。p≤h の有限例外も極限を変えない。従って δ_h=Σ_{m∈Z_h}1/(m(m+1))。無制限の実数周波数からサンプルする場合や、すでに p を固定して N だけ動かす場合とは母集団が異なる。

| m の探索上限 | h≥1 | h≥2 | h≥3 | h≥4 |
|---|---:|---:|---:|---:|
| 10^6 | 5361 | 84 | 4 | 0 |
| 10^7 | 12546 | 95 | 4 | 0 |
| 10^8 | 41908 | 110 | 4 | 0 |

h≥3 の四つは 1270, 4613, 56063, 56064。これらの 1/(m(m+1)) の和は 6.671325404743185×10^−7。Hurst の桁別個数 V(10^j) で、10^8 より先の寄与はどの h≥1 でも Σ_{j=8}^{15}(V(10^{j+1})−V(10^j))10^(−2j)+10^(−16) ≤ 1.022438×10^−11。最後の 10^−16 は 10^16 より先の全整数を入れた望遠和の上界。10の冪の端点は Hurst の表の範囲で零点でないため両端の規約も揃う。h=4 の値が正と決まれば、そのことだけで該当帯域が無限個の素数に適用される。

計算は Node.js で次を実行できる。値 2 はまだいずれの素数でも処理していない印。各素因子で符号を一度変え、平方因子があれば 0 とする。

```js
const bound = 100_000_000
const mu = new Int8Array(bound + 1).fill(2)
mu[1] = 1
for (let p = 2; p <= bound; p++) {
  if (mu[p] !== 2) continue
  for (let j = p; j <= bound; j += p) {
    mu[j] = mu[j] === 2 ? -1 : -mu[j]
  }
  for (let j = p * p; j <= bound; j += p * p) mu[j] = 0
}

const zeros = new Set()
const counts = [0, 0, 0, 0, 0]
let sum = 0
for (let m = 1; m <= bound; m++) {
  sum += mu[m]
  if (sum !== 0) continue
  zeros.add(m)
  for (let d = 1; d <= 4 && zeros.has(Math.floor(m / d)); d++) {
    counts[d]++
    if (d >= 3) console.log(m, d)
  }
}
console.log(counts.slice(1))
```

独立確認では M(1)=1, M(n)=1−Σ_{j=2}^n M(⌊n/j⌋) を用い、四つの m の先頭4個の M 値が順に (0,0,0,−4)、(0,0,0,−7)、(0,0,0,13)、(0,0,0,13) と出た。F_1270 の 490358 個の分数を gcd で直接列挙して cos の和を取ったときも、最初の3個の絶対値は 2×10^−11 未満、第4は −16.000000000019806。こちらは浮動小数点の健全性確認で、有限恒等式の根拠は整数計算である。

### Gaps

h≥4 の候補を全範囲で排除する証明は得ていない。Hurst の全零点座標が入手できれば、Z={m:M(m)=0} として Z∩(2Z+{0,1})∩(3Z+{0,1,2})∩(4Z+{0,1,2,3}) を取り、既存の計算範囲を再利用できる。外部コードの実行・Lean への接続は行っていない。
