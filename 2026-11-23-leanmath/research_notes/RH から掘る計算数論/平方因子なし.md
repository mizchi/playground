# 平方因子なし計数から、ゼータ零点を消す正の平均の最小幅へ

## 1. 何を計り、どの幅が必要か

### Takeaway

平方因子を持たない整数を、打ち切り付近で滑らかに重み付けして数える。通常の RH の下では、ゼータ零点の高さ γ は、対数スケールにおける誤差の実周波数 γ/2 を与える。「高さ T までのすべての極を正の局所平均で相殺するには、入力の最大値と最小値の比がどこまで必要か」という問題になる。

### Cited Findings

- 平方因子なし指示関数 μ² の Dirichlet 級数は ζ(s)/ζ(2s)。既に鋭い打ち切りの誤差の振動も 10¹⁸ までの計算もある。したがって、最初の少数の零点が平方因子なし計数に顔を出すことに新規性を置けない。[Mossinghoff, Oliveira e Silva, Trudgian](https://arxiv.org/pdf/1912.04972)
- 有限の高さについては臨界線の零点の検証も既存である。[Platt–Trudgian](https://arxiv.org/abs/2004.09765)

### Inferences

二次の Riesz 平均を S(x)=Σ_{n≤x} μ²(n)(1−n/x)²、規格化誤差を E(x)=[S(x)−2x/π²−1]/x^{1/4} と置く。重みの Mellin 変換は K(s)=2/[s(s+1)(s+2)]。Re s>1 で S の逆 Mellin 積分の係数は K(s)ζ(s)/ζ(2s) であり、s=1 の留数から 2x/π²、s=0 の留数から 1 を得る。RH の下で非自明零点 ρ の半分は Re s=1/4 にあり、分子 ζ(ρ/2)≠0。平均 ∫E(x exp(t))dν(t) によって、極 s=1/4+iγ/2 では ν の Fourier 変換 F(z)=∫exp(izt)dν(t) が周波数 γ/2 に作用する。重複度 h の極を完全に消す条件は F がその点で h 重以上に消えること。留数をすべて絶対収束級数に展開する必要はない。

高さ T 以下の正の零点を重複込みで数え、全条件を満たす確率測度 ν の台の直径の下限を L(T) とする。平行移動で消失の位数は変わらないので台は [−L/2,L/2] としてよい。以下は既知の結果を組み合わせて今回導出した**紙上の証明案**である。

**主張（RH 下の実周波数版）。T→∞ で L(T)=2 log T+O(log log T)。** とくに、平均が参照する x の最大値と最小値の比は T^{2+o(1)} になる。

1. **下界。** 台を [−a,a] とする。F(0)=1、|F(z)|≤exp(a|Im z|)。Jensen の公式を半径 R=T/2 で使うと、±γ/2 の零点（重複込み）から 2Σ_{0<γ<T}log(T/γ)≤(2a/π)R。境界に零点があれば極限で取れる。Riemann–von Mangoldt の公式を部分積分すると Σlog(T/γ)=∫₀ᵀN(t)dt/t=(T/(2π))(log(T/(2π))−2)+O((log T)²)。したがって 2a≥2log(T/(2π))−4+O((log T)²/T)。[零点計数の一次文献](https://arxiv.org/abs/2107.06506)
2. **全実線では正の解がある。** Ξ(z)=ξ(1/2+iz)=∫ exp(izu)Φ(u)du という規約の、正で偶な古典的密度を採る。φ(t)=Φ(t/2)/(2Ξ(0)) は確率密度で、その変換は Ξ(2z)/Ξ(0)。従って γ/2 で必要な重複度だけ消える。φ は [−1,1] 上で正の下限を持ち、|t| が大きいとき φ(t)≤C exp(−c exp(|t|))。最後の式は Φ の級数 (1.2) の exp(−πn² exp(2|u|)) に由来する。[Lagarias–Montague, (1.2), Lemma 3.1](https://rikkyo.repo.nii.ac.jp/record/8642/files/AA00610867_60-01%2C02_14.pdf) [Nakamura, Theorem 1.1](https://arxiv.org/abs/1504.03438)
3. **正の解を有限区間に移す。** 高さ γ の重複度を h として、各 0≤j<h に対する t^j cos(γt/2), t^j sin(γt/2) を座標に持つベクトル v(t) を取る。必要な条件は ∫v dν=0 である。座標数 d=2N(T) には ± 周波数と重複をすべて含めた。コンパクトな曲線 v([−A,A]) の凸包に原点が含まれなければ、強分離によって p(t)=u·v(t)>0 が [−A,A] 全体で成立する。ところが ∫p φ=0 である。
4. **分離との矛盾。** sup_{[−1,1]}|p|=1 と規格化する。Nazarov の不等式は区間 I と可測部分集合 B に対して sup_I|p|≤(C |I|/|B|)^{d−1} sup_B|p|。純虚指数のため指数実部の追加因子は 1。多重周波数の項 t^j exp(iλt) は、同じ λ の h 個の近接周波数での有限差分の線形結合によりコンパクト区間上一様に近似できる。各 λ の次数 h−1 以下の多項式全体を合わせて h 個の点を使えばよい。従って不等式は同じ d で極限に通る。B={|t|≤1 : p(t)≤(4C)^{-d}} が長さ 1 以上なら不等式に反する。よって ∫_{−1}¹pφ≥exp(−C₁d)（定数を増やす）。一方で外側は |p(t)|≤(C₂(1+|t|))^d である。A=log d+2log log d+C₃ と取ると t≥A において c exp(t)/2≥d log(C₂(1+t))。これは A で成立し、左辺の方が速く増える。そのため ∫_{|t|>A}|p|φ≤C₄ exp(−c exp(A)/2)<exp(−C₁d)。中間区間でも p>0 なので ∫pφ>0 となり矛盾する。[Nazarov, 1993](https://www.mathnet.ru/eng/aa397)
5. **結論。** 原点は凸包に属するので Carathéodory により高々 d+1 点を支持する確率測度で条件を満たせる。d=O(T log T) から 2A=2 log T+O(log log T)。下界と合う。有限だが大きい標本の高精度最適解を直接算出する手順や、一様な計数誤差の定数まではこの証明から得ていない。

**第 4 段の初等的な代替（同じ主係数を与える）。** 幅に関する上の証明から Nazarov の定理も外せる。h=1/d、0≤v<h とする。a_n=p(v+nh) は固有根 r_j=exp(±iγh/2) の d 次線形漸化式を満たす。各根を重複込みに挙げると n^ℓ r_j^n の ℓ<h_j の全てがこの漸化式を満たすからである。ここで h_j はその零点の重複度である。同じ r が格子上に重なってもよい。P(u)=∏(1−r_j u) と書くと P(u)Σa_n uⁿ の次数は d 未満。その係数の絶対値和は (Σ|[u^k]P|)Σ_{j<d}|a_j|≤2^d Σ_{j<d}|a_j|。[uⁿ](1/P) の絶対値は、幾何級数を掛けた項数から binom(n+d−1,d−1)≤[e(1+n/d)]^d で上から抑えられる。従って v を積分すると

∫_{n/d}^{(n+1)/d}|p(t)|dt ≤ [2e(1+n/d)]^d ∫₀¹|p(t)|dt。

負側には p(−t) を使う。A を 1/d の整数倍で log d+2log log d+C 以上の最小の値にとる。n/d≥A では指数 d log(2e(1+n/d)) は c exp(n/d)/2 以下である。φ の二重指数尾を掛けて和を取ると、両側を合わせた ∫_{|t|≥A}|p|φ は O(d exp(−c' exp(A)))∫_{−1}¹|p| で抑えられる。係数は大きい d で min_{[−1,1]} φ より小さい。分離関数 p は [−A,A] で正だから ∫pφ>0 である。この証明は同じ L(T)=2 log T+O(log log T) を与え、必要な解析的入力を ξ の Fourier 表現と零点計数に絞る。

**チェック用の別証明（次数のみ）。** {γ/2} を小さい順に貪欲に色分けし、同色の任意の二点を距離 1 以上離す。零点計数よりどの長さ 1 の区間にも O(log T) 個しかないので色数も O(log T)。重複零点のコピーは異なる色に置く。各色に周波数の負号を合わせて Λ とすれば、0 を加えても 1-separated（γ₁/2>1）。w(t) を一様な区間密度の自己畳み込みとし、その変換を W(u)=(sin(Bu)/(Bu))² にする。B を大きな固定定数にすると、分離条件と Σ_{k≥1}k^{−2}<∞ から各列の非対角絶対値和および Σ_{λ∈Λ}|W(λ)| は 1/3 未満。実対称行列 W(λ−λ') で c=−W_matrix^{-1}(W(λ)) を解けば ||c||₁<1/2、対称性で c_{−λ}=c_λ。よって w(t)[1+Σc_λ exp(iλt)] は非負であり、変換は Λ で消える。総質量を 1 に正規化し、全色を畳み込めば幅 O(log T) で重複条件も満たす。

### Gaps

- 最小幅そのものをこの形で述べた先行論文は今回の検索では特定できなかった。指数多項式の不等式、調和解析の補間、短時間の多モード振動抑制の既知の帰結である可能性がある。優先権・Lean 形式化は未確認。
- RH を外して複素数 z=(ρ−1/2)/(2i) で F を消す問題にも、同じ ξ の密度が使える。複素指数版の Nazarov の余分な因子は exp(O(|I|)) にとどまる。RH 独自の恩恵は全誤差項が同一の x^{1/4} スケールの実周波数にそろい、分子による相殺を除外できる点。低い二周波数だけなら RH の全域での証明は不要。
- 精密化目標は L(T)=2log T+O(1) かどうか、あるいは有限 T で正確な L(T) を正の原子解と双対分離関数で挟めるかである。余剰幅の符号・大きさと、実際に計数誤差が改善する範囲を分けて検証する。

## 2. 最初の二つは厳密に解けるか

### Takeaway

二つの単純零点を消すための最小幅は 8π/(γ₁+γ₂)=0.71487639… で、入力の倍率は 2.04393402…。この三点の重みを作る公式は振動制御の二モード入力整形にも存在する。

### Cited Findings

- 二モードを三つのインパルスで抑える設計式は減衰ゼロの場合に下の式に一致する。[Kobilov–Hong、2020 年、式 (2)–(8)](https://www.jkspe.or.kr/journal/view.php?number=6425)

### Inferences

b_j=γ_j/2 として a=2π/(b₁+b₂)、c=cos(b₁a)=cos(b₂a)<0。{−a,0,a} にそれぞれ w, w₀, w の質量を置く。w=1/[2(1−c)]≈0.2752522950、w₀=−c/(1−c)≈0.4494954099。変換は w₀+2w cos(az) なので両点で消える。幅 2a より短いと仮定し、台を中心化して偶対称化する。0<|t|<a では cos(b₁t)−cos(b₂t)=2sin((b₁+b₂)|t|/2)sin((b₂−b₁)|t|/2)>0。そのためこの差の積分を 0 にする測度は 0 に集中するが、δ₀ の変換は 1。これで下界も一致する。

### Gaps

同じ構成を γ₃ 以上に広げる場合の最適解の数・台・離散的な振る舞いは未検証。離散格子の線形計画だけでは連続問題の最適性の証明にならない。

## 3. 平方因子なし計数で何が観測できるか

### Takeaway

実測では [2¹⁸,2¹⁹) 内の等間隔の 64 点で、E の二乗平均平方根が 0.00737617 から 0.00070735 に下がった。この比較では二周波数を消した正の平均を使用した。高速な厳密計数アルゴリズムを示す数値ではない。

### Cited Findings

- 周波数を特定したゼータ零点の有限個の位置は、有限範囲の検証と照合できる。[Platt–Trudgian](https://arxiv.org/abs/2004.09765)

### Inferences

以下は手元で実行した Python 3 標準ライブラリによる再現コード。μ² を整数篩で作り、0 次・1 次・2 次の整数累積和を使って S(x) を評価した。零点の近似値と最終演算は倍精度であり、区間演算の証明ではない。

```python
from array import array
from math import cos, exp, isqrt, pi, sqrt

N = 2**20
squarefree = bytearray([1]) * (N + 1)
for d in range(2, isqrt(N) + 1):
    squarefree[d*d::d*d] = bytes(N // (d*d))

P, Q, R = [array("Q", [0]) for _ in range(3)]
for n in range(1, N + 1):
    v = squarefree[n]
    P.append(P[-1] + v)
    Q.append(Q[-1] + n*v)
    R.append(R[-1] + n*n*v)

def error(x):
    n = int(x)
    s = P[n] - 2*Q[n]/x + R[n]/(x*x)
    return (s - 2*x/pi**2 - 1) / x**0.25

b1, b2 = 14.134725141734694/2, 21.022039638771555/2
a = 2*pi/(b1+b2)
w = 1/(2*(1-cos(a*b1)))
def average(x):
    return w*error(x*exp(-a)) + (1-2*w)*error(x) + w*error(x*exp(a))

def rms(values):
    return sqrt(sum(x*x for x in values)/len(values))

for j in range(11, 19):
    points = [2**j*(1+u/64) for u in range(64)]
    print(j, rms([error(x) for x in points]), rms([average(x) for x in points]))
```

### Gaps

RH 下で、固定したコンパクトな幅が全零点を重複込みで消すことは第 1 節の Jensen 下界で排除される。分子は Re s=1/4 上で消えないので、打ち消し切れない極が残る。もし平均した非規格化誤差が o(x^{1/4}) なら、その片側 Mellin 変換 H は極の位置 s₀ で lim_{u↓0} u H(s₀+u)=0 を満たす（有界な初期区間を取り除き、残りは任意に小さく評価する）。有理的主項とコンパクト区間の補正は s₀ で正則であり、残る極と矛盾する。従って固定幅での改善は全域での指数改善を意味しない。観測値を全 x に対する一様誤差定数に変換する部分は未解決である。
