# フェアリー列の同時零点をどこまで既存結果と区別できるか

## Farey 和と倍周波数の恒等式のどこまでが既知か

### Takeaway

分母が N 以下の既約分数を円周上で一度ずつ数えた周波数 k の和 A_N(k) は、Kanemitsu–Yoshimoto が2000年の定理1の証明で、今回用いた約数和と同じ式に書いている。この入口を新規の定理とは数えない。[Kanemitsu–Yoshimoto, p.437](https://publi.math.unideb.hu/paper/597/download/10_5486_PMD_2000_2327.pdf)

### Cited Findings

- 同論文の記号は C_x(n)。分母ごとの Ramanujan 和、Farey 点での余弦和、Σ_{d|n} d M(⌊x/d⌋) の三つを直接等号で結び、Yoshimoto (1998) を引用する。共役対称性から複素指数に変えても和は同じ。この論文では、p の冪乗周波数を持つ Weierstrass 関数に対する RH 誤差も扱う。[Kanemitsu–Yoshimoto, Theorems 1 and 3](https://publi.math.unideb.hu/paper/597/download/10_5486_PMD_2000_2327.pdf)
- Weber の Proposition 2.1(ii) でも同じ構造が一般の関数について明示される。単独周波数を代入すると、完全等比級数が d|k でだけ d を与え、上記の式に戻る。[Weber, pp. 6, 14–15](https://arxiv.org/pdf/1906.07628)
- 2016年には、n 以下の円分多項式の積の一次係数を M(n) で表す計算が投稿されている。任意次数の係数を対象にした元の質問と回答も確認した。このスレッドは次数3の同時零点の一覧を与えていない。[元の質問と回答](https://math.stackexchange.com/questions/1665576/any-formul%C3%A6-for-products-of-consecutive-cyclotomic-polynomials)

### Inferences

p∤r で A_N(pr)−A_N(r)=p A_{⌊N/p⌋}(r) は2000年の式の約数を二分した直接の系。m=⌊N/p⌋ と置き、最初の h 個の高調波が全て一致する条件 Z_h={m≥1: M(⌊m/d⌋)=0 (1≤d≤h)} も約数和の三角性から従う。Newton 恒等式からは、円分多項式の積を定数項1に正規化したときの次数1,…,hの係数が同時に 0 となる条件とも同値。これらを個別の数学的新発見と数えると強すぎる。

### Gaps

同時消滅する m の数表、または N 以下の素数 p のうち該当する比率の極限をこの Z_h に対して評価した既存報告は、今回の照合では特定できなかった。用いた検索語は Farey quadrature / exactness / trigonometric design、Ramanujan sums、Mertens simultaneous zeros and dilates、consecutive cyclotomic polynomial coefficients、下記の数列の先頭項。多項式の係数列を次数や向きを変えて符号化したデータまで照合し尽くしたわけではない。

## OEIS と Hurst の実データから独立に何を検証できるか

### Takeaway

OEIS の (Z_1) の座標表から (Z_3) の四つの例が再現できた。2026年11月24日版の主要項401,918列を照合した範囲では、(Z_3) および (Z_2) の先頭項を同じ並びで持つ別の登録は見つからなかった。[A028442 の座標ファイル](https://oeis.org/A028442/b028442.txt) [OEIS の主要項ダウンロード](https://oeis.org/stripped.gz)

### Cited Findings

- A028442 の b-file は最初の 10,000 座標を含み、末尾は 5,631,198。集合に読み込み、m と ⌊m/2⌋, ⌊m/3⌋ の所属を調べた結果は 1270, 4613, 56063, 56064。これらは既存の個別座標から導出できる。A171910 は各桁までの全零点数を収録している。[A028442](https://oeis.org/A028442) [A171910](https://oeis.org/A171910)
- OEIS の stripped.gz（Last-Modified 2026-11-24 06:00:30 UTC、33,916,541 バイト、SHA256 `8477787eda6cc601f4de973b2d4007dc7e6fa648ac2cd63dfa6d960ebadfc52c`）を展開ストリームで照合した。項の両側のコンマまで含め、列中のどの位置でも、1270,4613,56063 および 329,332,333,428 はともに0件。より長い 1270,4613,56063,56064、および 329,332,333,428,811,814 に対する公式検索 API もともに null。[OEIS の主要項](https://oeis.org/stripped.gz)
- Hurst は 10^16 以下について全零点 366,567,325 個を記録した。2018年の論文に桁別総数の表がある。著者の GitHub の mertens リポジトリを main の再帰的ファイル一覧（85項目、切り詰めなし）とリリース v1.0（添付0件）まで調べた。この調査では全座標配布は確認できなかった。公開コードは再計算を可能にする。[Hurst, §6.1](https://arxiv.org/abs/1610.08551) [著者リポジトリ](https://github.com/greg-hurst/mertens) [リリース](https://github.com/greg-hurst/mertens/releases)

### Inferences

実験の候補は、既知の一次元零点を倍数スケールで交差させたときの具体的な分類と、そこからの素数密度の評価。個別零点の座標の発見日と、組み合わせた性質の最初の記述日は区別する。

### Gaps

OEIS の主要項照合は全 b-file・説明文に対する数値全文検索を含まない。著者の私的データ、別名の公開アーカイブ、どこかの b-file の深い位置にある一致はこの検査から判断できない。

## 10億まで計算すると候補と密度区間はどう変わるか

### Takeaway

今回の分割篩の上限は 10^9。h≥1,2,3,4 の件数は順に 141,121、116、4、0。三次で消える m は四つのままで、四次の最初の例の有無は依然未解決。全零点数は独立した Hurst の表に一致する。[Hurst, §6.1](https://arxiv.org/abs/1610.08551)

### Cited Findings

- 有限範囲の素因子の符号・平方因子に基づく篩で M の全値を得る方法は Hurst §2 に記載。今回もブロック末尾の平方根以下の素数を使い、最後に大きな素因子を補った。[Hurst, §2](https://arxiv.org/abs/1610.08551)
- 下の区間評価が外部から使うのは 10^9,…,10^16 の各桁までの零点個数。Hurst の原表で照合した。[Hurst, §6.1](https://arxiv.org/abs/1610.08551)

### Inferences

200,000整数ずつ昇順に処理。各ブロック [l,u] の各 n に対し、p≤√u で n を割る異なる素数について (−p) の積 a を計算し、p²|n があれば 0 にする。|a|=n なら μ(n)=sgn(a)、それ以外は μ(n)=−sgn(a)。μ の累積が 0 のときだけ n を Set に追加し、順に ⌊n/d⌋ が Set にあるかを調べた。主要配列は符号付き32ビット200,000個。1≤n≤10^9 では |a|≤n のためあふれない。10^8 で M=1928 と件数 (41908,110,4,0)、10^9 で M=−222 と件数 (141121,116,4,0)。追加区間に Z₂ が6個、Z₃ は0個。

固定 m の帯域における素数の極限割合は 1/[m(m+1)]。δ_h=Σ_{m∈Z_h}1/[m(m+1)] を 10^9 で打ち切り、V(X) を X 以下の M の零点個数とする。h≥1 で全ての余項は、Σ_{j=9}^{15}(V(10^{j+1})−V(10^j))10^(−2j)+10^(−16) < 3.031×10^−13。したがって 6.6713254047×10^−7 < δ₃ < 6.6713284355×10^−7、0 ≤ δ₄ < 3.031×10^−13。下限の丸めは下向き、上限の丸めは上向き。有限分類・密度の存在・この数値評価は無条件で、RH は該当帯域での正規化した求積誤差の漸近的な小ささに用いる。

### Gaps

10^9 超で四次例が存在しないとは結論できない。今回の確認は公開済み全零点リストとの照合ではなく、独立した篩と公開の桁別総数・先頭座標との照合である。
