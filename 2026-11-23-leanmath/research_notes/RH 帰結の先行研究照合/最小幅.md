# ゼータ零点を相殺する正の平均の最小幅

## 1. どの既存問題と同じか

### Takeaway

高さ T 以下の各非自明零点 ρ について、zρ=(ρ−1/2)/(2i) に重複度だけ零点を持つ F(z)=∫exp(izt)dν(t) を考える。ν は実直線上の確率測度で、L(T) はその台の直径の下限とする。通常の RH を置くと zρ=γ/2 は実周波数である。有限スペクトルを持つ実指数多項式が、一度も零点を持たずにいられる区間の最大長（上限）と同値であり、この定式化と二周波数の式には既存研究がある。ゼータスペクトルの T に関する有界剰余まで述べた先行定理は、下の照合では確認できなかった。

### Inferences

**双対の同値。** ρ の重複度を m とし、各 0≤k<m について tᵏexp(izρt) の実部・虚部を座標 v(t) に入れる（共役条件の重複を取り除く）。平行移動で零点の位数は変わらない。区間 I 上で v の積分が 0 となる確率測度が存在する条件は 0∈conv(v(I))。I がコンパクトならこの凸包もコンパクトで、条件が失敗する場合に限り実線形結合 p=u·v が I 全体で正になる。RH 下の単純零点なら従って Kozma–Oravecz の M という双対問題そのものである。

**二周波数。** 0<b₁<b₂<3b₁ で a=2π/(b₁+b₂)、c=cos(ab₁)=cos(ab₂)<0。{−a,0,a} に質量 (1,−2c,1)/(2−2c) を置くと両点が消える。中心化した、これより狭い区間では cos(b₁t)−cos(b₂t) が t=0 以外で正である。両周波数を消せば差の積分も 0 となり、質量が 0 に集中して矛盾する。この方法で有理周波数比の仮定を使わず KO 定理3の K=1 の式を確認できる。

## 2. 二次項をどこまで詰められるか

### Takeaway

以下は一次文献に載っていた結論ではなく、今回得た紙上の強化である。上記の複素零点条件で **L(T)=2 log T+O(1)**。RH 下では実周波数 γ/2 の同じ主張となる。倍率で言えば exp L(T) は T² の定数倍の間に挟まる。以前の O(log log T) の余剰を、格子で取る差分方程式の特性根の分布を用いて有界にした。上界の絶対定数は数値化していない。

### Cited Findings

- 零点計数 N(u) は重複込みで u/(2π)(log(u/(2π))−1)+O(log(2+u))。これを角度分布の一様部分と変動に分ける。[Hasanalizade–Shen–Wong](https://arxiv.org/abs/2107.06506)
- Φ が正、偶で、Ξ(z)=∫exp(izu)Φ(u)du。φ(t)=Φ(t/2)/(2Ξ(0)) とすると変換は Ξ(2z)/Ξ(0) で、すべての zρ で必要な位数だけ消える。Lemma 3.1 の級数の最初の項・全項から、ある正定数 c,C で exp(−C exp(|t|))≤φ(t)≤C exp(−c exp(|t|)) が全 t に成り立つ。下界は |t|≥0 において各項が正であることと n=1 項、コンパクト区間の正の最小値から従う。[Lagarias–Montague、式 (1.2)、Lemma 3.1](https://rikkyo.repo.nii.ac.jp/record/8642/files/AA00610867_60-01%2C02_14.pdf)

### Inferences

**下界。** 台を [−L/2,L/2] に中心化すれば |F(z)|≤exp((L/2)|Im z|)、F(0)=1。半径 R=T/2 で Jensen の公式を使って ±γ/2 の対を数えると
`L ≥ (4π/T) Σ_{0<γ≤T} log(T/γ) = 2log(T/(2π))−4+O(log²T/T)`。
複素版でも |zρ|=√(γ²+(β−1/2)²)/2 への変更は和に O(Σγ⁻²)=O(1) の影響しかない。境界を僅かに越える点の対数は負なので、下界計算に足してもよい。

**上界ではまず RH 下の実周波数で説明する。** d=2N(T)、h=2π/T、B=dh/2=log(T/(2π))−1+O(log T/T)。大きい T のみを扱う。根のリストに rⱼ=exp(±iπγ/T) を重複込みで入れ、
`P(z)=∏(1−rⱼ z), q=exp(−1/log T)`
と置く。

1. **円 |z|=q 上の両側評価。** H(θ)=log|1−q exp(i(θ+u))| とする。H の円平均は 0 で、Fourier 展開 −Σ_{n≥1}qⁿcos(n(θ+u))/n と Parseval から ||H||₂≤(πΣ1/n²)^{1/2}。全変動は 2log((1+q)/(1−q))=O(log log T)、||H||∞=O(log log T)、いずれも u に一様である。log|P(q exp(iu))| は H を ±θⱼ の計数測度で積分したもの。両半円で θ=πγ/T と変数を換え、N(u) の主項の微分に置き換えると、主項の密度は T/(2π²)[log(T/(2π²))+log|θ|] dθ。定数密度の寄与は平均値ゼロで消え、log|θ| は (−π,π) 上 L² なので残りは O(T)。各半円の Stieltjes 部分積分で残る境界値と誤差積分は O(log T)(||H||∞+Var(H))。よって e^{−C₁T}≤|P(q exp(iu))|≤e^{C₁T}。
2. **差分方程式の外挿。** 第1節の任意の分離候補 p に対し 0≤v<h における aⱼ=p(−B+v+jh) を考える。多重根でも nᵏrⁿ は (shift−r)^{k+1} により消える。従って形式的母関数は Σ_{n≥0}aₙzⁿ=Q(z)/P(z) で Q の次数は d 未満。Q は P(z)Σ_{j<d}aⱼzʲ の d 次未満への切断。Cauchy から |[zᵏ]P|qᵏ≤e^{C₁T}、従って Σ|[zᵏ]Q|qᵏ≤(d+1)e^{C₁T}Σ_{j<d}|aⱼ|qʲ。さらに 1/P の |z|=q 内に極がなく、円上の大きさは e^{C₁T} 以下。この円で Q/P の係数を取れば
`|aₙ| ≤ exp(C₂T+n/log T) Σ_{j<d}|aⱼ|`。
q⁻ᵈ に相当する重みを落としても d/log T=O(T) である。v で積分すると各区間 [−B+nh,−B+(n+1)h] の ∫|p| はこの指数因子と、初期区間の重みなし積分 M=∫_{−B}ᴮ|p| の積以下となる。左側は p(−t) で同様。
3. **ξ 密度の内外比較。** A を log T+C₀ 以上の最小の格子端点に取る。p>0 が [−A,A] で成立すると仮定する。φ の下界と eᴮ=O(T) から、初期区間の ∫pφ≥e^{−C₃T}M、M>0。外側の各区間の左端 tₙ=−B+nh≥A では n=(tₙ+B)T/(2π)。log T+C₀≤t における (t+B)e^{−t} の単調減少により、C₀ を充分大きく取れば C₂T+n/log T≤(c/2)e^{tₙ} が尾部全体に成立する。そこで ∫_{A}^∞ |p|φ≤CMΣ_{j≥0} exp(−(c/2)e^{A+jh})。e^{jh}≥1+jh なので、和は exp(−(c/2)eᴬ)/(1−exp(−(c/2)eᴬh)) 以下。eᴬh≥2π e^{C₀} なので分母は 0 から離れる。負側の尾も含めて e^{−C₃T}M より小さくなるように C₀ を選べる。[−A,A] の残りでは p>0。ところが ∫pφ=0 なので矛盾する。
4. **正の原子解。** 分離不可能性により凸包が原点を含む。従って有限支持の確率測度 ν を [−A,A] に取れる。以上から L≤2A=2log T+O(1)。
5. **複素零点版。** rⱼ=exp(ih zρ) に変えても、その偏角は ±πγ/T、絶対値は exp(O(1/T))。実線形な座標の複素共役が作る指数も、ρ↦1−conj(ρ)、ρ↦conj(ρ) のゼータの対称性により全零点のリストの中にあるため、必要項数 d を増やさずに済む。q|rⱼ|<1。|z|=q で単位半径の場合と比較した log|1−rⱼz| の変化は高々 O(T⁻¹)/(1−q exp(O(T⁻¹)))=O(log T/T)。d 根全部でも O(log²T) なので第1段はそのまま成立する。負側の p(−t) も r の逆数に同じ議論が使える。ξ の Fourier 恒等式は整関数の恒等式であり、複素零点と重複に対する ∫pφ=0 も成立する。従って幅の存在自体は無条件の命題にできる。RH 特有の算術的な意味は、平方因子なし計数の ζ(s)/ζ(2s) の全非自明極が Re s=1/4 にそろい、分子での相殺がなく、単一の x^{1/4} の規格化でこの測度を使える点である。

### Gaps

この導出は紙上での検算である。外部査読、定数を数値化した上界、L(T)−2log T の極限や最適な定数は未確認。格子を使うのは外挿の証明であり、上の凸分離が与える正測度の原子には等間隔を課していない。

## 3. 有限 T でどこまで構成を確認できたか

### Takeaway

異なる10個の高さで、差分方程式の多項式 P そのものに**全係数が正**であることを零点表の誤差込みで確認した。これらの高さでは P の係数を総和で割ると格子点 0,h,…,dh の確率測度が得られ、全指定周波数が正確に消える。T=1000 では 649 零点、1299 係数、台の幅の上界 4π·649/1000=8.1555745…。この処方の最適性は含まない。

### Cited Findings

- Andrew Odlyzko の最初の 100,000 零点の表には絶対誤差 3·10⁻⁹ と記載されている。この公称精度と零点の順序を入力として使用した。[原データの説明](https://www-users.cse.umn.edu/~odlyzko/zeta_tables/)
- Poincaré の古典理論では、正実軸に根を持たない多項式の非負係数倍数は存在する。ここで計算した条件は乗数を 1 にできるかという、より厳しい条件である。[Hong–Riggs、§1、定理2](https://arxiv.org/pdf/2301.00331)

### Inferences

T=1000 の直前・直後の表中の値は γ₆₄₉=999.791571557、γ₆₅₀=1001.349482638。それぞれの公称誤差を加味しても 1000 を厳密に挟む。端の二係数は厳密に 1。以下の「下限」は残る全係数の区間下端の最小値を下向きに小数第2位まで丸めたもの。二次因子の一部に負の一次係数があることも含めて検査した。

各 T に対して θⱼ=πγⱼ/T の保証区間を有理数で作り、cos の単調性と交代 Taylor 級数で 1−2cos θⱼ z+z² の係数を挟む。多項式を γ の昇順の偶数番・奇数番で二分する平衡木で掛け、各乗算・加算を外向きに丸める。指数幅の比較に使う格子上では、多項式係数を正規化した測度の変換は P(exp(ihz))/P(1)。周波数 z=±γ/2 に対し exp(ihz) は P の根である。区間演算は真の係数を包含するため、実在する測度の厳密な消失を導ける。区間の中点を代入した離散係数をそのまま使う場合は数値近似になる。

以下の再現コードは標準 Python 3 を使用する。

```python
from fractions import Fraction as F
from itertools import islice
from math import factorial
from urllib.request import urlopen

url = "https://www-users.cse.umn.edu/~odlyzko/zeta_tables/zeros1"
with urlopen(url) as table:
    zeros = [F(line.decode().strip()) for line in islice(table, 1000)]
error = F(3, 10**9)
scale = 10**15
pi_lo = F(3141592653589793238, 10**18)
pi_hi = pi_lo + F(1, 10**18)

def cos_bounds(x):
    term = total = F(1)
    for k in range(1, 17):
        term *= -x*x / ((2*k-1)*(2*k))
        total += term
    return total-x**34/factorial(34), total

def floor(x):
    return x.numerator // x.denominator

def ceil(x):
    return -floor(-x)

def product(factors):
    if len(factors) == 1:
        return factors[0]
    left, right = product(factors[::2]), product(factors[1::2])
    out = [[0, 0] for _ in range(len(left)+len(right)-1)]
    for i, (a, b) in enumerate(left):
        for j, (c, d) in enumerate(right):
            products = (a*c, a*d, b*c, b*d)
            out[i+j][0] += min(products)
            out[i+j][1] += max(products)
    return [(a//scale, -((-b)//scale)) for a, b in out]

for T in (30, 50, 80, 100, 125, 150, 200, 250, 500, 1000):
    included = [g for g in zeros if g < T]
    m = len(included)
    assert included[-1] + error < T < zeros[m] - error
    factors = []
    for g in included:
        lo = pi_lo*(g-error)/T
        hi = pi_hi*(g+error)/T
        assert 0 < lo < hi < pi_lo
        mid = (floor(-2*scale*cos_bounds(lo)[1]),
               ceil(-2*scale*cos_bounds(hi)[0]))
        factors.append([(scale, scale), mid, (scale, scale)])
    coeffs = product(factors)
    assert len(coeffs) == 2*m + 1 and all(a > 0 for a, b in coeffs)
    internal_lower = min(a for a, b in coeffs[1:-1])
    print(T, m, internal_lower // (scale//100))  # 下限の 0.01 単位
```

**零点直前を含む連続域の追加検査。** さらに m=1,…,50 の各 [γₘ,γₘ₊₁) で T が区間内を動く不確かさも有理区間に入れた。固定 m のまま両端の公称入力誤差を外側に膨らませる。対象となる γⱼ≤T なので角度が π に達する場合は cos の下限を厳密な −1 とする。各区間を必要に応じて二分した結果、合計53部分区間、最大分割深さ1、全内部係数区間の下端の最小値は 1.030906852536849 だった。T<γ₁ では P=1 なので、**0<T<γ₅₁（約146.000982487）の全実数 T** で正性が得られる。上の単点・ここでの連続版ともに、Odlyzko の入力データの公称誤差を依拠点とする。

単点のコードの最初の for T の前までを実行し、以下を追加すれば再現できる。

```python
def certify(m, low, high):
    factors = []
    for g in zeros[:m]:
        lo = pi_lo*(g-error)/high
        hi = pi_hi*(g+error)/low
        cos_lo = F(-1) if hi >= pi_lo else cos_bounds(hi)[0]
        mid = floor(-2*scale*cos_bounds(lo)[1]), ceil(-2*scale*cos_lo)
        factors.append([(scale, scale), mid, (scale, scale)])
    return min(a for a, b in product(factors)[1:-1])

def verify(m, low, high, depth=0):
    lower = certify(m, low, high)
    if lower > 0:
        return [(depth, lower)]
    assert depth < 6, "この精度では判定できない"
    mid = (low + high)/2
    return verify(m, low, mid, depth+1) + verify(m, mid, high, depth+1)

rows = [row for m in range(1, 51)
        for row in verify(m, zeros[m-1]-error, zeros[m]+error)]
print(len(rows), max(d for d, x in rows), min(x for d, x in rows))
# 53 1 1030906852536849  (最後の値は 10^15 倍)
```
