# ゼータ零点から作る多項式の係数の正性

## 1. どこまで示せるか

### Takeaway

**紙上の命題。** γ を ζ の非自明零点の正の虚部（重複込み）、m=N(T)、h=2π/T とし、
`P_T(z)=∏_{0<γ≤T}(1−2cos(πγ/T)z+z²)=Σ_{k=0}^{2m}p_k z^k`
と定める。通常の RH の下で、十分大きいすべての実数 T とすべての 0≤k≤2m に対して pₖ>0。したがって {0,h,…,2mh} に重み pₖ/P_T(1) を置くと、各 γ/2 で指定された重複度だけ Fourier 変換が消える。台の直径は厳密に 4πN(T)/T。この式は最小幅 L(T) の構成的上界である。

### Cited Findings

- 重複込みの零点計数を N(v)=M(v)+R(v), M(v)=v(log(v/(2π))−1)/(2π) とすると、|R(v)|≤C log(2+v)。M(0)=0 と連続に延長する。次節では θ=0 の近くの零点に対してもこの v 依存性を維持する。[Hasanalizade–Shen–Wong](https://arxiv.org/abs/2107.06506)
- Ξ(z)=ξ(1/2+iz) は偶な位数1の整関数。通常の RH 下ではその Hadamard 積を正負二つずつまとめて Ξ(z)/Ξ(0)=∏_{γ>0}(1−z²/γ²) と書ける。指数因子は偶性で定数になる。∑γ⁻²<∞ は零点計数からも従う。Ξ は実直線上で厳密に正な密度 Φ の Fourier 変換であり、特に φ(x)=Φ(x/2)/(2Ξ(0)) の変換は Ξ(2u)/Ξ(0) である。[Lagarias–Montague, (1.1), (1.2), Lemma 3.1](https://arxiv.org/pdf/1106.4348)
- Cauchy の係数積分を正実の鞍点の周りで評価する手法は古典的である。Hayman が正規近似の条件を与え、De Angelis は固定した多項式の高いべきの係数の正性を扱う。ここでは T ごとに零点も次数も変化する一つの多項式の係数を扱うため、以下で主弧・残りの円周を直接抑える。[Hayman (1956)](https://doi.org/10.1515/crll.1956.196.67) [De Angelis (2003)](https://vdeangel.xula.edu/Publications/asy.pdf)

### Inferences

両端から m−C T 番目までの正性は零点の虚部の計数公式だけで従う。中央の残り O(T) 個を扱うために、RH と実数上での φ の厳密な正性を用いる。後半の議論は単純零点も線形独立性も仮定しない。

構成的上界は `L(T)≤2log(T/(2π))−2+O(log T/T)`。今回のスリット領域による下界は `L(T)≥2log(T/(2π))−2−2log2+o(1)` で、上下界の差は 2log2+o(1)。旧来の円板 Jensen 下界 `L(T)≥2log(T/(2π))−4+O(log²T/T)` との比較では差は 2+o(1) だった。定数項の極限の存在はまだ導いていない。最小次数の等間隔格子に限った定数項の最適性も同じノートの末尾で扱う。[スリット下界と格子幅の制約](幅の定数.md)

### Gaps

以下は新たに得た手計算の証明で、Lean 化・外部査読・優先権確認を経ていない。ある絶対的 T₀ の存在を得るが、具体的な T₀ や 146 以降の全有限範囲を証明したわけではない。有限範囲を別に認証する目的は残る。

## 2. 端から m−C T 番目までの符号をどう保証するか

### Takeaway

単位円内の正の半径 r を動かして係数積分を取る。r=e^{-s} の s を大きい定数 K を用いて K/T まで小さくしても、正実方向の寄与が勝つ。低い零点に対して粗い一様誤差 O(log T) を使うと失われる範囲である。

### Cited Findings

- 以下の加法的誤差は Riemann–von Mangoldt の計数公式を Stieltjes 部分積分した結果である。定数 C を数値化する場合には誤差 R(v) の明示評価が利用できる。[Hasanalizade–Shen–Wong](https://arxiv.org/abs/2107.06506)

### Inferences

**主項の係数。** |z|<1 で定数項0の対数を選び、
`log P_T(z)=T f(z)+E_T(z), f(z)=Σ_{n≥1} Aₙ zⁿ, Aₙ=Si(nπ)/(π²n²), Si(x)=∫₀ˣ sin(t)dt/t`。
実際に [zⁿ]log P_T=−(2/n)Σ_{γ≤T}cos(nπγ/T) で、dM 主項を部分積分すれば Aₙ を得る。半周期ごとに符号が替わり絶対値が減ることから Si(nπ) は正の二定数間にあり、Si(nπ)=π/2+O(1/n)。よって Aₙ≍1/n²。R(v) に対する部分積分から [zⁿ]E_T=O(log T) が n に一様に成り立つ（積分の微分因子 n を先頭の 1/n が打ち消す）。従って n≤c√(T/log T) では [zⁿ]log P_T>0。指数の冪級数を取れば、同じ範囲ですべての pₖ>0。以下の鞍点評価につなぐには k≤T^{1/4} までで十分である。

**単位円近くでの微分評価。** D=z d/dz、r=e^{-s}、K/T≤s≤s₀=1/4、θ∈[−π,π] とする。j=1,2,3 に対して
`|Dʲ E_T(r e^{iθ})| ≤ Cⱼ s^{-j} log(2+Ts)   (|θ|≤s)`。    (1)

確認のため G_s(u)=log(1−e^{-s+iu}) とする。log P_T は u=±πγ/T における G_s(u+θ) の和である。u が 0 から π、または −π から 0 までの半円ごとに部分積分する。誤差は端点の R(T) と、±R(T|u|/π) を u 微分したカーネルに掛ける積分に分かれる。循環距離 ||u||=dist(u,2πℤ) と書けば |∂ᵘ Dʲ G_s(u)|≤Cⱼ(s+||u||)^{−j−1}（∂ᵘ は u の1回微分）。|θ|≤s なら積分は定数倍を除いて
`∫_{−π}^π log(2+T|u|)/(s+||u+θ||)^{j+1} du ≪ s^{-j}log(2+Ts)`。
|u|≤||u+θ||+s として変数を s で割れば、余剰は ∫₀^∞log(2+x)/(1+x)^{j+1}dx<∞ で抑えられる。境界 u=±π のカーネルは有界で、O(log T) もこの評価に含まれる。

**離れた方向の誤差。** θ=|θ|≥s で
`|Re(E_T(r e^{iθ})−E_T(r))| ≤ C log(2+Tθ)[1+log(1+θ/s)]`。    (2)

実関数 H_s(u)=log|1−r e^{iu}| の部分積分を二つの角度で引く。重みが |u|≤2θ 上で O(log(2+Tθ)) であり、この部分の |H_s'(u+θ)| と |H_s'(u)| の積分は O(1+log(1+θ/s))。これは |H_s'(v)|≤C/(s+||v||) を使う。|u|>2θ 上では両角度を結ぶ円弧上で原点までの距離は |u|/2 以上で、|H_s''(v)|≤C/(s+||v||)²。したがって残りは O(θ∫_{2θ}^π log(2+Tu)du/u²)=O(log(2+Tθ))。境界 u=±π からの差は θ≤π/4 なら O(θ log T)、それ以上なら O(log T·(1+log(1/s))) で、いずれも (2) に含まれる。

**円周での絶対値の減衰。** 主項の落差 TΣ Aₙe^{-ns}(1−cos(nθ)) は、|θ|≤s で cTθ²/s 以上、s≤|θ|≤π で cT|θ| 以上。前者は n≤1/s までの項、後者は |θ|≤1 なら n≤1/|θ| までの項、1≤|θ|≤π なら n=1 だけで得る。Re E_T は θ の偶関数なので前者の誤差は (1) を2回積分して O(θ²s^{-2}log(2+Ts))。後者の誤差を y=T|θ| と書けば (2) から O(log²(2+y))。K を十分大きく選べば、Ts≥K または y≥K でそれぞれ主項に吸収できる。したがって、絶対定数 c>0 により
```
|P_T(r e^{iθ})| / P_T(r) ≤ exp(−cTθ²/s)   (|θ|≤s)
|P_T(r e^{iθ})| / P_T(r) ≤ exp(−cT|θ|)    (s≤|θ|≤π).        (3)
```
また b(r)=D²log P_T(r)≍T/s>0、|θ|≤s で |D³ log P_T(r e^{iθ})|≪T/s²。主項の対応する評価は Aₙ≍1/n² から得る。誤差は (1) により同じく吸収できる。

**r が単位円から離れる場合。** 0<r≤e^{-s₀} では [zⁿ]E_T=O(log T) を絶対収束の範囲で使えば、a(r)=Dlog P_T(r)≍Tr、b(r)≍Tr>0、円周全体で |D³ log P_T|≪Tr。主項の落差は n=1 の項から cTr(1−cosθ) 以上。誤差の差は |1−cos nθ|≤n²(1−cosθ) により O(r log T(1−cosθ))。従って円周での比は exp(−cTrθ²) 以下となる。

**係数積分の符号。** a(0)=0 であり b(r)>0 なので r↦a(r) は 0<r≤e^{-K/T} で増加する。k=a(r) として Cauchy の公式を使う。|θ|≤s で
`log P_T(r e^{iθ})−log P_T(r)−ikθ=−bθ²/2+O(T|θ|³/s²)`。
M を大きな定数として |θ|≤M/√b では三次剰余の絶対値は O(M³/√(Ts))。K を M の後で十分大きくすればこの区間は |θ|≤s に含まれ、余剰は例えば 0.1 以下。従って主弧の積分の実部は c₀/√b 以上。一方で M/√b<|θ|≤s の絶対積分は (3) から O((1/√b)∫_{c₁M}^∞ exp(−x²)dx)、s<|θ|≤π では O(e^{−cTs}/T)。前者は M を、後者は K を大きくすれば、合わせて主弧より小さい。比の定数は M,K と独立に選べる。0<r≤e^{-s₀} の場合も b≍Tr、三次微分 O(Tr)、全円周での二乗指数減衰から同じ議論になる。k≥T^{1/4} で Tr→∞ のため三次剰余が十分小さい。よって両範囲で pₖ>0。

**鞍点が覆う次数。** Si(nπ)=π/2+O(1/n) より T Df(e^{-s})=(T/(2π))log(1/s)+O(T)（s≤s₀）。s=K/T で (1) の j=1 の誤差は O_K(T)。従って a(e^{-K/T})=Tlog T/(2π)+O_K(T)=m+O_K(T)。ある絶対定数 C₀ を取り、k≤m−C₀T 全体まで正性が従う。P_T は相反多項式なので上側の端にも同じ議論が通る。ここまででは RH を用いなかった。

### Gaps

C₀ は絶対定数であって、先に固定した K に依存する。K は証明中に T や k に依存させていない。大きな未知の C₀ でも次節で扱う区間は固定されたコンパクト集合となる。

## 3. 中央帯の係数をどう接続するか

### Takeaway

係数を中心 k=m の周りで格子幅 h に換算すると、RH 下で ξ の厳密に正な Fourier 密度 φ が局所極限となる。ここでまだ符号が判らない係数を確率分布として扱う推論は使わない。

### Cited Findings

- ξ の偶な Fourier 密度 Φ の級数では t≥0 で各項が正である。従って Φ はどの固定コンパクト区間でも正の下限を持つ。この事実により、符号を保つために必要な誤差を絶対誤差で評価できる。[Lagarias–Montague, Lemma 3.1](https://arxiv.org/pdf/1106.4348)

### Inferences

**局所極限。** |u|≤T/2 で
`Q_T(u)=exp(−imhu)P_T(exp(ihu))/P_T(1)=∏_{0<γ≤T}(1−sin²(πu/T)/sin²(πγ/(2T)))`
と置き、それ以外で 0 と定める。固定 u で各因子は 1−4u²/γ² に収束する。0≤πγ/(2T)≤π/2 では sin(πγ/(2T))≥γ/T なので、尾の差の和は O(u² Σ_{γ>G} γ^{-2}) で T に一様。したがって RH の下で Q_T(u)→Ξ(2u)/Ξ(0)。

**実軸の一様可積分性。** 積の各根の絶対値は1であり、|1−e^{iv}|²≤r^{-1}|1−re^{iv}|²。r=e^{-K/T} と取ると円周の積全体で |P_T(e^{iθ})|≤r^{-m}|P_T(re^{iθ})|。正規化の補正は
`r^{-m} P_T(r)/P_T(1)=∏_{0<γ≤T}(1+sinh²(K/(2T))/sin²(πγ/(2T))) ≤ exp(C K² Σγ^{-2})`
で T に依存しない。(3) と θ=hu から |u|≥K/(2π) で |Q_T(u)|≤C_K exp(−c'|u|)、残りの有界区間は C_K 以下になる。従って Q_T は Ξ(2u)/Ξ(0) に L¹(du) で収束する。

**Fourier 反転。** 整数 j、|j|≤m で
`p_{m+j}/(h P_T(1))=(1/(2π))∫ Q_T(u) exp(−ihju)du`。
L¹ 収束により `sup_{|j|≤m}|p_{m+j}/(hP_T(1))−φ(hj)|→0`。|j|≤C₀T なら |hj|≤2πC₀、φ のこの区間上の最小値は厳密に正。十分大きなすべての T で中央帯が正となる。第2節と合わせて全係数を覆う。

**数値照合（浮動小数点）。** Odlyzko の零点表を用い、二次因子を高さ順の偶数番と奇数番に交互に分けた平衡積、円周率に通常の倍精度値を用いて、上の密度を確認した。φ は Lemma 3.1 の級数を n=7 で打ち切り、±4 の区間で 1/2000 刻みの和で正規化した。これは証明ではなく尺度の検算である。h, 2π, Ξ(0) の正規化を変えると一致しない。[Odlyzko の表](https://www-users.cse.umn.edu/~odlyzko/zeta_tables/)

### Gaps

この命題の RH の使いどころは、実数 γ から組み立てた中心積の極限を Ξ と同定する段階である。逆向きの含意を示していない。中心分布の一様誤差定数・有効な T₀、最小幅の真の定数項も未決である。「高いべき」や「零点測度の弱極限」を扱った既存結果は同じ結論を直接与えないが、他の文献との重複の可能性は残る。
