# ゼータ零点を消す正測度の最小幅の加法定数

## 格子漸化式の増大率の係数は何か

### Takeaway

RH 下の実周波数 γ/2（0<γ≤T、多重度を数える）を殺す確率測度の台の最小幅を L(T) とする。今回の外挿から、下記の明示的な定数 D について

```
limsup (L(T)−2log T) ≤ 2 log((D+1/(2e))/π) < −3.1917519217 .
```

これは格子の特性多項式の全係数に符号条件を課さない上界である。

### Cited Findings

- HSW の零点計数から N(y)=(y/(2π))(log(y/(2π))−1)+O(log(2+y))。零点数は正の虚部について多重度込み。[Hasanalizade–Shen–Wong](https://arxiv.org/abs/2107.06506)
- Ξ(2z)/Ξ(0) の Fourier 確率密度 φ は正かつ偶。theta 級数の n=1 項と残りの指数減衰によって、log φ(t)=−π exp(|t|)+O(1+|t|)。2倍した周波数の規約なので指数は exp(|t|)。[Lagarias–Montague, Lemma 3.1](https://rikkyo.repo.nii.ac.jp/record/8642/files/AA00610867_60-01%2C02_14.pdf) [Nakamura, Theorem 1.1](https://arxiv.org/abs/1504.03438)

### Inferences

d=2N(T), h=2π/T, B=dh/2=log(T/(2π))−1+o(1)。θⱼ=πγⱼ/T とし、P(z)=∏(1−ze^(iθⱼ))(1−ze^(−iθⱼ))。q=exp(−1/(log T)²) と置く。固定 α>0 の exp(−α/log T) の後に α↓0 とする操作を、この q では直接実行できる。

g_q(v)=log|1−qe^(iv)| は円平均 0。その全変動と絶対値の最大は O(loglog T) なので Riemann–von Mangoldt の剰余の部分積分は O(log T loglog T)。各半円で主項の密度を代入して足すと、円上で一様に

```
(1/T) log|P(q e^(iu))| = f(u)+o(1),
f(u)= (1/(2π²)) ∫_{−π}^π log(|v|/π) log|1−e^(i(v+u))| dv .
```

定数密度は円平均0で消える。q↑1 で g_q→g_1 in L² なので、Cauchy–Schwarz により畳み込みの収束は平行移動 u に一様。単位円上の根と T が零点そのもののときの ±π の重なりも許す。D=max f−min f と置く。

分離関数を一般化指数多項式 S(t) とし、[−A,A] で正、しかも ξ の零点・導関数の消滅により ∫Sφ=0 と仮定する。各 offset x∈[0,h) で sₙ=S(−B+x+nh) は P を分母とする形式的母関数を持つ。分子は最初の d 項だけで決まり、その k 番目係数は Σ_{j=0}^k Pⱼs_{k−j} (0≤k<d)。円 q での Cauchy 評価は |Pⱼ|≤q^(−j)exp(T max f+o(T))、逆数の係数は |[z^k](1/P)|≤q^(−k)exp(−T min f+o(T))。例えば両評価を掛けると d 個までの和と q^(−n) が残り、n≥d について

```
|sₙ| ≤ exp(T D+o(T)+n/(log T)²) Σ_{i=0}^{d−1}|sᵢ| .
```

o(T) は n・offset に依存しない。反対側は S(−t) に適用し、初期値の和を x で積分すると H=∫_{−B}^B S(t)dt。A≥B なら正性から H>0。中央の寄与は少なくとも exp(−πeᴮ−O(1+B))H=exp(−T/(2e)+o(T))H。

A=log T+c+O(h) を格子端点に取り、πeᶜ>D+1/(2e) とする。このとき c>−log(2π)−1 なので A>B。外側の左端 t=−B+nh≥A において n/(log T)²=(t+B)T/(2π(log T)²)。最初の区間では o(T)、以後も e^(t−A) に対する相対誤差は一様に o(T)。φ の多項式因子 exp(O(1+t)) も同様。したがって任意の小さな固定 η>0 に対し外側各区間の絶対量は H exp(T D+o(T)−(π−η)e^t) 以下。格子和は e^(jh)≥1+jh と h eᴬ≈2πeᶜ により最初の項の有界倍で済む。ηを十分小さくして両尾を足しても中央より指数的に小さい。中間区間でも S>0、ゆえに ∫Sφ>0 で矛盾。コンパクト凸包の分離定理から所要の確率測度が存在し、最後に c を閾値に下ろす。

### Gaps

この limsup は実際の漸近定数を同定しない。計算は十分大きい T に対するもので、有効な高さ閾値を指定していない。

## ポテンシャルの振幅 D はいくらか

### Takeaway

0.4529580799415 < D < 0.4529580799449。最大は u=0、最小は u=π で達成される。

### Cited Findings

- ここで使うのは前節で明示した円上の畳み込みで、その密度の出所は零点計数の主項。[Hasanalizade–Shen–Wong](https://arxiv.org/abs/2107.06506)

### Inferences

円上で −log(|v|/π) と log 2−log|1−e^(iv)| はともに非負、偶で中心からの距離について単調減少。両者の畳み込みは定数項を除き f に比例する。各超準位集合は中心対称な円弧で、二円弧の重なりの長さが中心間距離の増加とともに減少することを各水準で積分すれば単調性が出る。Fourier の余弦係数を部分積分すると、Si(x)=∫₀ˣsin(t)dt/t として

```
f(u) = π⁻² Σ_{k≥1} Si(kπ) cos(ku)/k² ,
D=f(0)−f(π)=(2/π²)Σ_{k odd}Si(kπ)/k² .
```

数値区間は次の手順。k が奇数なら Si(kπ)=π/2+J(kπ), J(v)=∫₀^∞ exp(−vt)/(1+t²)dt。π/2 の項を全て足すと π/8。k<20 は Si の Taylor 級数を400項（100桁程度のπ値、110桁Decimal演算）使った。ここでは次項より小さい打切り誤差に加え、出力の外向き丸め幅 10⁻¹³ は中間項の相殺による演算誤差を上回る。21≤k≤100000 では J(v) を 1/v−2/v³+24/v⁵−720/v⁷ とそれに 40320/v⁹ を加えた値で挟んだ。これは (1+t²)⁻¹ の有限等比級数の剰余の符号から出る。残りは 0<J(v)<1/v と積分比較により 1/(π³ 100000²) 未満。丸め前の D の下端は 0.452958079941575…、上端は 0.452958079944802…。上界定数の評価は −3.1917519217275 < 2 log((D+1/(2e))/π) < −3.1917519217172。

### Gaps

この数値計算は初等級数の打ち切り誤差を組み込んだ手計算・スクリプト検算であり、Lean による区間演算証明は未実施。

## スリット領域の下界と照合するとどの差が残るか

### Takeaway

スリット平面での Blaschke 評価により liminf(L(T)−2log T)≥−2log(2π)−2−2log2。上で得た保証との幅は 3.8702965723 未満。従来の円板 Jensen の下界と照合した数値は 4.4840022112 未満だった。

### Cited Findings

- 下界に使う外部の数論入力は零点計数。余剰項 O(log T) で足りる。[Hasanalizade–Shen–Wong](https://arxiv.org/abs/2107.06506)

### Inferences

確率測度の台を [−a,a] に平行移動し、その Fourier 変換を F とすると F(0)=1, |F(z)|≤exp(a|Im z|)。R=T/2 でスリット領域 Ω=C＼((−∞,−R]∪[R,∞)) を使う。平方根は原点で正とし、Re√(R²−z²)≥|Im z| は |R²−z²|≥||z|²−R²| の帰結。従って F(z)exp(−a√(R²−z²)) の絶対値は Ω で 1 以下、原点で exp(−aR)。写像 w=z/(R+√(R²−z²)) は Ω から単位円板へ写り、逆は z=2Rw/(1+w²)。指定された ±γ/2 に対応する有限 Blaschke 積で割り原点で評価すると

```
aR ≥ 2 Σ_{0<γ<T} arcosh(T/γ).
```

γ=T の寄与は0。I(s)=∫₀¹ x^(s−1) arcosh(1/x) dx=√π Γ(s/2)/(2sΓ((s+1)/2)) は部分積分で求まる。I(1)=π/2, I′(1)=−π(1+log2)/2。上の和を dN(t) で積分し、主項の密度 (log(t/(2π)))/(2π) dt を代入。t<2 を切り分け、[2,T] 上で arcosh(T/t) の全変動 O(log T) を使えば計数剰余による誤差は O(log² T)。2a=L に戻すと主張の下界を得る。既存の円板 Jensen の加法定数 −2log(2π)−4 より 2−2log2≈0.613706 大きい。

### Gaps

この上下界から L(T)−2log T の収束や、格子多項式の係数正性は出ない。仮に別の手法で全係数正が示されれば L≤2B の構成的な上界に置き換わり、スリット下界との差は 2log2 まで縮む。

### 最小次数の等間隔格子で刻みを縮める限界

RH 下で U>T, h=2π/U とする。0<hγ/2<π なので、異なる正の周波数とそれらの負号対は円上で衝突しない。指定された多重度まで消える、0,h,…,dh 上の非負係数フィルターの最小候補次数は d=2N(T)。この次数の消去多項式は P_{T,U}(z)=∏_{γ≤T}(1−ze^(iπγ/U))(1−ze^(−iπγ/U)) の定数倍である。導関数消滅の条件は z=exp(iht) の局所微分が非零なため根の重複度にそのまま移る。

任意の 0<r<1 に対し、係数がすべて非負なら P(r)≥|P(−r)|。実際には P(±r)>0。そこで S=log(P(−r)/P(r)) とする。各正零点からの寄与は log[(1+2r cosθ+r²)/(1−2r cosθ+r²)]、θ=πγ/U。θ∈(0,π) で cosθ は減少し、この対数は cosθ の増加関数なので S は U の増加とともに増える。

c>0 を固定し U=T(1+c/log T) と置く。f_r(u) は前節で g_1 を g_r に替えたポテンシャルとする。RvM の主密度 U/(2π²)[log(U/(2π²))+log|v|] は |v|≤πT/U 上に乗る。円を満たす場合の g_r(v+π)−g_r(v) の定数密度項は 0。除かれた両端の合計長は 2πc/log T+o(1/log T)、端点での被積分関数は −log((1+r)/(1−r))。固定 r では連続なので、不足した端点部分から正の項が残る。log|v| 部分の積分は全円の積分に収束する。部分積分の計数誤差は O_r(log T)。したがって

```
S/T → f_r(π)−f_r(0) + (c/π) log((1+r)/(1−r)) .
```

r↑1 で最初の差は有限な −D に収束し、第2項は +∞ に発散する。先に c を決め、次に固定 r を決め、最後に T→∞ とすれば S>0 となる。U についての単調性により、十分大きい T に対し U≥T(1+c/log T) すべてで係数非負が不可能。この条件は任意の固定 c>0 で成り立つ。従ってこの次数・この格子であり得る非負フィルターの幅は 4πN(T)/U≥4πN(T)/T−o(1)。U=T が実際に達成可能かはここでは用いない。T が零点ちょうどのときの U=T では正負対が −1 で衝突するが、ここで排除した側は常に U>T なので論証に影響しない。

この制約は、等間隔・最小次数・Nyquist 未満という三条件を満たす多項式についてのもの。任意の連続測度、非等間隔の原子、あるいは d より高い次数を認めた問題に対する下界は先のスリット不等式の範囲に留まる。
