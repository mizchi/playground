# playground

思いつきを気軽に試すための総合的な実験用リポジトリ。

## 構成

実験ごとに `<date>-<name>/` 形式のディレクトリを切り、その中で完結させる。

```
playground/
├── README.md
├── AGENTS.md
├── 2026-09-24-foo/
│   ├── README.md
│   └── ...
└── 2026-10-01-bar/
    └── ...
```

- `<date>`: 作業を始めた日付 (`YYYY-MM-DD`)
- `<name>`: 内容を表す短い名前 (kebab-case)

日付プレフィックスにより、ディレクトリ一覧がそのまま時系列になる。

## ルール

- **各ディレクトリは独立させる。** 他の実験ディレクトリのコードを import・参照しない。
- **依存関係やツール設定はディレクトリ内に閉じる。** `package.json`, `Cargo.toml`, `moon.mod.json`, `.gitignore` などは各ディレクトリに置く。ルートにはワークスペース設定を置かない。
- **ルートには共有ファイルを置かない。** ルートにあるのは `README.md`, `AGENTS.md` など、リポジトリ全体の説明だけ。
- **使い回したくなったらコピーする。** 別の実験のコードを流用したい場合は、参照ではなくコピーする。
- 各ディレクトリには、何を試したか・どう動かすかを書いた `README.md` を置くことを推奨する。

## 新しい実験を始める

```sh
mkdir "$(date +%Y-%m-%d)-my-idea"
cd "$(date +%Y-%m-%d)-my-idea"
```
